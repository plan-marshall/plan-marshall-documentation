== Overview

This document specifies how *plan-marshall-mcp* (`PM-MCP`) meets the coding agents installed on a machine: the detection of a coding agent's environment for the operator checks, the Host Integration Table, the version probes, and the embedded client bundle with its `bundle-manifest.json` schema. The client profile schema and the placeholder rendering are specified in the link:https://github.com/plan-marshall/pm-mcp-core/blob/main/doc/specification/client-profiles.adoc[Client Profiles Specification].
