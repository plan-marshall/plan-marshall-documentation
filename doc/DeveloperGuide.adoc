== Overview

The developer guide describes how the implemented system is built, extended and tested. It describes what the code does today; what is still to be built is stated in the link:Requirements.adoc[Requirements] and the link:Specification.adoc[Specification], and the listing of the modules is the link:specification/module-structure.adoc[Module Structure Specification].
