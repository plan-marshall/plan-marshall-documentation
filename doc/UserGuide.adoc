== Overview

The user guide describes how the implemented system is installed, configured and operated, from the side of the operator and of the user of a coding agent host. It describes what the system does today; what is still to be built is stated in the link:Requirements.adoc[Requirements] and the link:Specification.adoc[Specification], and why the system works as it does is explained in the link:Concepts.adoc[Concepts].
